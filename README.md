# Lumen-AI-Toolkit
A list of tools Lumen uses. Basics of listing, reading and searching files.
Lumen is my own personal local Ai. It is used a personal secretary that can read and record files for me.

This repository contains the custom tools I created to help Lumen interact with approved local files and structured data. The project runs locally through Ollama and Open WebUI.

### Features
-List files from approved directories
-Read text and markdown files
-Search files using text matching
-Inspect CSV files and return structured information
-Support AI tool and function calling
-Keep private files and AI processing on local hardware

### Technologies
-Python
-Ollama
-Open WebUI
-Docker
-Markdown
-CSV
